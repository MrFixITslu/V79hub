The owner accepted the deployed logo/upload and automatic draft-status UI on October 14, 2026 and requested enabling publication after approval. This enables the existing exact-delivery approval path. It creates no approvals and authorizes no particular provider post or newsletter send.

Run `scripts/marketing-production-enable-publication.py` directly on the Acer. It uses pinned, integrity-checked support scripts. Before any restart it verifies the finalized UI receipt, exact healthy images and Marketing Compose stack, signed idle campaign ledger, existing G2 boundaries, current customer/provider/account/billing state, and unchanged file-mounted secrets. Active production, approved/running/uncertain deliveries, or automatic production due within ten minutes prevent activation.

The command captures a fresh online SQLite backup with an integrity check, Marketing data/assets excluding the live SQLite files, and runtime/Compose/environment/key recovery material. These are encrypted with the owner's exact public key in a private per-attempt keyring. It copies the three encrypted backups and manifest to the Acer. Every ciphertext checksum and the full decrypted stream hash must match before it requests activation. Plaintext backups are never written to the Acer filesystem. Existing recovery rehearsals remain applicable because neither application image nor database schema changes.

The only resolved Compose change is `V79_MARKETING_PRODUCTION_PUBLISH_ENABLED=1` on `v79-marketing`. Keys, images, resources, mounts, network membership, commands, users, other environment settings and all other services must match. Docker-generated hostnames and ordering of identical bind entries are compared explicitly.

A durable switch marker prevents another recreation after an uncertain outcome. No automatic restart retry or rollback occurs. A disabled overlay and exact original-stack rollback command are retained for reviewed operator recovery; returning the flag to zero cannot undo a provider post. The success receipt is written only after the signed list/replay/founder/MFA checks, private draft and authentication checks, and preservation checks pass. Activation probes never forge a fresh MFA assertion or call a provider.

Approval is bound to the immutable bundle and delivery digest. The worker waits for the approved time, rechecks current owner permission, assets and destination, and records the provider receipt. A lost receipt is uncertain and is never automatically retried. Standing automatic draft production does not approve publication.
