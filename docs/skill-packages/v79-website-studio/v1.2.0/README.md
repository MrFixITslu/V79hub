This preserves the full v1.1 master and its original Interactive Resources reference and adds November 2026 collaboration, photoreal service stories, reader-first educational posts, conversion measurement and stricter release gates. Nothing replaces the Marketing or YouTube skills.

## Which app control to use

- **Existing V79 Website Studio in Hub Skill Manager:** edit the existing skill, paste the entire `SKILL.md` (under the 32 KB field limit), review its diff and save/activate using your normal fresh-MFA approval. Preserve existing worker assignment and name; version the change.
- **Hub ZIP Skill Packages:** import the ZIP as a separate package, review its hash, approve it through the existing MFA screen, then select only relevant scheduled instruction recipients. Avoid creating confusing duplicate worker instructions if the plain-text Website Studio skill is already active. ZIP packages do not execute code on import.
- **ChatGPT standalone Skill:** use the package only where its skill-import format is supported; do not assume Hub import installs it into every app automatically.

Suggested built-in hook: integrity ON; static UI reviewer only when a developer hook runtime is explicitly available. Scheduled assignments: Technology review as the normal technical reviewer, Marketing review only when website campaign reviews are explicitly needed; leave CEO/COO unchecked unless owner requests a brief. All assignments are instructions-only.

The website studio is independent from the Marketing, YouTube Production and Interactive Learning Post specialist skills; they collaborate by explicit campaign and tenant hand-offs.
