# Website Studio release acceptance

- Approved specific design and scope; branch provenance and diff captured.
- Rights, claims, logos, tenant data and consent checked.
- Keyboard, screen reader and reduced-motion journeys reviewed; mobile and desktop layouts verified.
- Routes, cards, back, reload, deep links, share links, SEO metadata and llms.txt pass.
- Performance and errors measured; forms, Hub/Tiquet and analytics receipts verified where applicable.
- Security and role isolation, migrations, back-up recovery, health and rollback plan verified.
- Owner explicitly authorises production release; deployment lock/backup verified; smoke test and read-back recorded.

Do not mark a gate PASS without observable dated evidence.
