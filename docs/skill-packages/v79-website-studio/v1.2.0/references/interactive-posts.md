# Reader-first interactive posts

The full lesson must appear on the resource page without any requirement to share it. Use Explain, Demonstrate, Practise, Check and Recap, with age-18-friendly language, exercises visitors can actually perform, accessible interactions, clearly sourced screen captures, captions, accurate share preview, direct link, card link, reload and browser-back tests. Subscriber extras may be gated separately only. One post at a time requires owner review.
