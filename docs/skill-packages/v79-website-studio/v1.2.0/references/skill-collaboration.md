# Website Studio + specialist skills: division of responsibility

1. Preserve the client's approved Marketing skill and per-user version.
2. Website Studio owns website information architecture, service pages, conversion routes, embed behaviour, accessibility and technical release.
3. Interactive Learning Post owns educational lesson content and activity design, not deployment.
4. YouTube Production owns scripts, storyboards, titles, thumbnails, clips, subtitles and YouTube ad drafts, not automatic platform publication or spending.
5. Exchange drafts by explicit campaign and tenant ID, version pins, verified claims, rights ledger, asset digest, reviewer and lifecycle status. No cross-tenant copying, shared credentials or silent skill replacement.
6. Website previews must be reviewable before merge. Deployment, publishing and paid ads each require their own explicit authorisation.
